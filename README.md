# Pam · Mi visión — PWA por capítulos

Publica los archivos en la raíz del repositorio `LordJeferies/pam-mi-vision`. GitHub Pages debe servir desde la rama `main`, carpeta `/`.

- Inicio → Selección de recorrido → Preparación → Capítulos → Reflexión → Cierre → Plan.
- 6, 8 o 14 capítulos por sesión según modalidad.
- Voz sintetizada del navegador (puede variar en iOS) y música ambiental generada en el navegador.
- Guardado local de reflexiones, capítulos, preferencias y checklist. Exportación TXT.
- Instalación PWA y caché sin conexión después de la primera carga.
- Los datos no se sincronizan entre dispositivos ni se envían a GitHub.
- No hay afirmaciones de eficacia clínica ni garantía de obtener empleo mediante visualización.

Para actualizar GitHub desde la Mac, ejecutar `PUBLICAR_MAC.command` con el ZIP en Descargas, o usar el comando mostrado en ChatGPT.

# Pam — Mi visión
PWA estática para GitHub Pages. Música ambiental ORIGINAL sintetizada con Web Audio (no requiere pistas externas). Narración opcional mediante la voz del navegador (Web Speech API), cuyo soporte y mezcla con el audio varía en iOS/Safari. Diario y checklist guardados solo en localStorage del dispositivo. Service Worker ofrece consulta offline tras la primera carga. No recopila datos ni envía información a servidores.

## Publicación
Crea un repositorio público nuevo, por ejemplo `pam-mi-vision`, y publica la raíz desde `main` en Settings > Pages. Página esperada `https://lordjeferies.github.io/pam-mi-vision/`. La exportación del diario es local. GitHub Pages es público: no subas notas personales al repositorio.
